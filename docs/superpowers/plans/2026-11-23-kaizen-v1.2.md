# Kaizen v1.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add rewards (praise, quotes, milestones, vibration), deeper progress (category stats, weekly review, share image), personal features (habit, favourites, calendar reminder) and four reliability fixes to Kaizen, with schema v2 migration.

**Architecture:** Same as v1: vanilla ES modules, no build. New pure modules (`schema`, `quotes`, `rewards`, `personal`, `week`, `reminder`) hold all logic and are unit-tested; UI modules render via `el()`/`svg()` only. A design-approval gate (Task 7) sits between logic and UI.

**Tech Stack:** HTML/CSS/JS ES modules, `node --test`, Playwright e2e, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-23-kaizen-v1.2-design.md` (and the v1 spec it extends)

## Global Constraints

- Everything in the v1 plan's Global Constraints still applies (CSP, banned sinks, relative paths, no dependencies, English UI).
- `SCHEMA_VERSION = 2`; v1 documents migrate on load and on import.
- Limits: habit name 60, note 140, reflection 280 chars; favourites ≤ 500 ids per list.
- Habit never affects `dayFraction`, score, streak, `bestStreak` or the 4/4 quote.
- Weeks start Monday. Reflection prompt shows on Sunday only; the saved reflection is keyed by that week's Monday.
- Milestone ids exactly: `streak-3 streak-7 streak-14 streak-30 streak-60 streak-100 score-1.05 score-1.10 score-1.25 score-1.50 score-2.00`.
- Quote ids `q01…`, fact ids `x01…` (existing), ≥ 55 quotes, each with `text`, `by`, `source.label`.
- Version `1.2.0` in `package.json`, `src/version.js`, `sw.js` CACHE.
- Four tabs: `#today`, `#progress`, `#history`, `#settings`.

## Review Focus

1. **Existing phone data (v1) on first open of v1.2** — loads, nothing lost, no "corrupt" banner. → Task 1 unit test with a real v1 fixture + Task 12 e2e seeding v1 JSON.
2. **Tap just after midnight with yesterday's screen still showing** — no change to yesterday; today's screen appears. → Task 11 e2e with `page.clock.setSystemTime`.
3. **Habit name / reflection containing HTML** — rendered literally. → Task 10 e2e.
4. **Un-ticking after 4/4 or after a milestone** — quote card hides but quote stays assigned; milestone stays earned (not re-awarded, not removed). → Task 3 unit + Task 8 e2e.
5. **Two copies of the app open** — both converge on the union of actions done in each, last write of the same field wins. → Task 11 e2e with two pages.
