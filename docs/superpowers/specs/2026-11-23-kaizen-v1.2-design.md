# Kaizen v1.2 — Design Spec

Agreed with the owner through a grill-me interview on 2026-11-23. Builds on `2026-11-22-kaizen-design.md`; everything there still holds unless changed here.

## Decisions

| # | Feature | Decision |
|---|---|---|
| 1 | Praise after each tick | A short line under the date for ~3 s, ~30 variations, says how many tasks are left. Also for the personal habit. |
| 2 | Quote on 4 of 4 | A quote card replaces "All four done" for the rest of the day, with an ink-stamp animation. ~60 quotes, verified attribution, each with a source. One quote per completed day; no repeat until all shown (shuffle bag). If the day is un-completed the card hides; re-completing shows the same quote. |
| 3 | Quote mix | Qur'an & hadith on effort/consistency; Muslim scholars (e.g. Ibn al-Qayyim, al-Ghazali, Ibn Khaldun); classic philosophers (Seneca, Marcus Aurelius, Epictetus; paraphrases labelled); a few modern voices (e.g. James Clear). Never use a misattributed "internet quote". |
| 4 | Milestones | Streak 3, 7, 14, 30, 60, 100 days; score ×1.05, ×1.10, ×1.25, ×1.50, ×2.00. Each shown once (longer toast + vibration), then listed on a trophy shelf in History with the date earned. |
| 5 | Vibration | `navigator.vibrate`: short on tick, longer pattern on 4/4 and milestones. On/off switch in Settings (default on). Silently does nothing where unsupported. |
| 6 | Category stats | Progress: per category, completion rate since first day and its own current streak. |
| 7 | Weekly review | Weeks Monday–Sunday. Progress shows this week: done per day, strongest and weakest category, the week's notes. On Sundays a reflection prompt "What made this week better than last?" with a text box (max 280 chars); saved per week, shown in the review, included in backups. |
| 8 | Share progress | Button on Progress → image card (score, streak, curve, journal style) → Android share sheet; falls back to downloading the PNG. No notes or task text in the image. |
| 9 | Personal habit | Optional 5th card the owner names (max 60 chars) and switches on in Settings. Own tick, note, streak. Not in the ×1.01 score and not toward the 4/4 quote. |
| 10 | Favourites | ☆ on task cards and on the fun fact. Favourites list in History. |
| 11 | Calendar reminder | Settings: time picker (default 08:00) + "Add to Google Calendar" (prefilled daily repeating event via calendar.google.com link) + "Download calendar file" (.ics) for other calendar apps. |
| 12 | Fixes | (a) notes save on every keystroke, never lost on swipe-away; (b) any action first checks for a new day — a tap after midnight never edits yesterday; (c) best streak = longest run actually in history (undo can lower it back); (d) two open copies stay in sync via the `storage` event. |
| 13 | Data | Schema v2 with automatic migration from v1; v1 backups still import. All data stays on device. |
| 14 | Navigation | Four tabs: Today, Progress, History, Settings. Backup moves to Settings. |

## Data (schema v2)

New top-level fields added to the v1 document (all other fields unchanged; `Day` objects unchanged):

```jsonc
{
  "schemaVersion": 2,
  "settings": { "vibration": true, "reminderTime": "08:00", "habitName": "", "habitEnabled": false },
  "habitDays": { "2026-11-23": { "done": true, "doneAt": "…ISO…", "note": "" } },
  "favourites": { "tasks": ["h03"], "facts": ["x12"] },
  "reflections": { "2026-11-23": "Monday key → reflection text" },
  "milestones": { "streak-7": "2026-11-29" },
  "quoteBag": ["q04", "q17"],
  "quotes": { "2026-11-23": "q31" }
}
```

Migration v1 → v2 fills defaults. A backup or stored document is accepted if it is valid v1 or v2; anything else is rejected/treated as corrupt exactly as in v1.

## Security & privacy (additions)

- New free text (habit name, habit note, reflection) is rendered with `textContent` only and length-limited (60 / 140 / 280).
- Import validation covers every new field strictly (whitelisted keys, types, lengths, id patterns, real dates).
- The share image contains only score, streaks and the curve.
- The Google Calendar link carries only the event title "Kaizen — today's 4 tasks", the time and the app URL. No personal data.
- CSP unchanged; canvas and blob downloads need no relaxation.
